# Multimodal Late-Fusion Engine

## 1. Architectural Philosophy
Multimodal verification combines diverse signals into a single explainable verdict. Rather than deploying an opaque end-to-end black box neural network that risks hallucinating explanations or suffering from catastrophic forgetting, Phase 2 implements an **explainable late-fusion architecture**.

### Core Guiding Principles:
1. **Evidence-Grounded Primacy**: Direct external evidence consensus from reputable fact-checkers and primary sources dominates weak heuristic media signals.
2. **Explainability**: Every decision is auditable with explicit feature dimensions and decision rationale statements.
3. **No Fabricated Certainty**: Synthetic and manipulation signals are probabilistic; a low-confidence heuristic never automatically overturns strong factual evidence.

---

## 2. Late Fusion Feature Vector

```python
class FusionFeatureVector:
    stance_refute_score: float      # Weighted proportion of evidence refuting claim [0.0 - 1.0]
    stance_support_score: float     # Weighted proportion of evidence supporting claim [0.0 - 1.0]
    temporal_penalty: float         # Penalty for recycled / outdated / anachronistic claims [0.0 - 1.0]
    media_manipulation_score: float # Max of synthetic probability and ELA tampering [0.0 - 1.0]
    evidence_sufficiency: float     # Cumulative domain-weighted retrieval density [0.0 - inf)
    cross_modal_alignment: float    # Congruence between claim text and visual OCR [0.0 - 1.0]
```

---

## 3. Decision Matrix Hierarchy

Decisions are resolved sequentially through a deterministic rule cascade:

```
[Candidate Features]
        │
        ▼
1. Evidentiary Refutation Dominance?
   (stance_refute_score >= 0.65)
        │── YES ──> CONTRADICTED
        └── NO
             │
             ▼
2. Cross-Modal Mismatch or Severe Media Tampering?
   (cross_modal_alignment < 0.70 OR media_manipulation_score > 0.75)
        │── YES ──> MISLEADING
        └── NO
             │
             ▼
3. Temporal Recycling Penalty?
   (temporal_penalty > 0.60)
        │── YES ──> OUTDATED
        └── NO
             │
             ▼
4. Evidence Sufficiency Gate?
   (evidence_sufficiency < 0.70)
        │── YES ──> INSUFFICIENT_EVIDENCE
        └── NO
             │
             ▼
5. Corroborated Evidence Support?
   (stance_support_score >= 0.70)
        │── YES ──> SUPPORTED
        └── NO
             │
             ▼
6. Conflicting / Mixed Stance Balance
        └───> MISLEADING
```

---

## 4. Cross-Modal Alignment Checker (`cross_modal_alignment.py`)
Identifies "cheapfakes" — real, unedited photos or videos presented with false, contradictory captions.
- Compares claim text tokens against OCR text tokens from keyframes or images.
- If an image caption claims "Violent riots breaking out in downtown city" but visual OCR shows "Annual Summer Carnival and Parade Festival 2019", the Jaccard alignment score drops below 0.10.
- Penalizes `cross_modal_alignment` by 0.45, routing the verdict to `MISLEADING` with clear audit notes explaining the visual caption disparity.

---

## 5. Statistical Calibration Disclaimer
The verdict confidence scores generated by the decision matrix are heuristic confidence bounds designed for interpretability. They are **NOT** claimed to be fully calibrated Bayesian posterior probabilities on unseen wild distributions (calibration will be formally evaluated in Phase 3).
