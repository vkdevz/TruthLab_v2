# Evaluation Protocol & Benchmark Standards
## Multimodal Evidence-Aware Misinformation Verification System

---

## 1. Experimental Integrity & Non-Fabrication Policy

This protocol establishes strict rules for empirical validation:
- **No Fabricated Benchmarks**: All evaluation metrics, confusion matrices, and latency tables must be generated by executable scripts running against verified test splits.
- **Leakage Prevention**: Zero claim overlap between training sets (baseline/fine-tuned NLI) and validation/test sets. Split partitioning must occur by *publisher* or *event cluster*, not random uniform sampling.
- **Reproducibility Guarantee**: Every experiment must be runnable via a deterministic script with pinned random seeds (`seed = 42`).

---

## 2. Dataset Partitioning & Split Strategy

### 2.1 Partitioning Principles
1. **Temporal Splitting**: For time-sensitive evaluation, test samples must be strictly temporally subsequent to training samples (e.g. Training: events up to 2022; Testing: events from 2023–2026). This tests real-world temporal generalization.
2. **Domain/Source Splitting**: Claims from a specific news outlet or fact-checker (e.g. Snopes) must not appear across both train and test splits to prevent the model from memorizing publisher-specific phrasing styles.
3. **Multimodal Splitting**: For image/video test sets, synthetic images generated by a specific generator (e.g., Midjourney v6) must be evaluated as out-of-distribution if trained on earlier generators (e.g., Stable Diffusion 1.5).

### 2.2 Split Ratios
- **Training Set**: 70% of available annotated samples.
- **Validation Set (Tuning & Calibration)**: 15% (used for hyperparameter selection and Temperature Scaling parameter $T^*$).
- **Test Set (Held-Out Final Evaluation)**: 15% (evaluated once for final reporting).

## 3. Mathematical Metric Definitions

### 3.1 Classification Performance Metrics
Given $K = 5$ classes in veracity taxonomy $\mathcal{Y}$:

- **Per-Class Precision, Recall, and F1**:
$$\text{Precision}_k = \frac{\text{TP}_k}{\text{TP}_k + \text{FP}_k}, \quad \text{Recall}_k = \frac{\text{TP}_k}{\text{TP}_k + \text{FN}_k}, \quad \text{F1}_k = \frac{2 \cdot \text{Precision}_k \cdot \text{Recall}_k}{\text{Precision}_k + \text{Recall}_k}$$

- **Macro-Averaged F1 (Primary Metric)**:
$$\text{Macro-F1} = \frac{1}{K} \sum_{k=1}^K \text{F1}_k$$
*Note*: Macro-F1 is selected over Accuracy because misinformation classes are naturally imbalanced in real-world corpora.

### 3.2 Evidence Retrieval Quality Metrics
- **Mean Reciprocal Rank (MRR@k)**:
$$\text{MRR@}k = \frac{1}{|Q|} \sum_{i=1}^{|Q|} \frac{1}{\text{rank}_i}$$
where $\text{rank}_i$ is the position of the first ground-truth verifying or refuting evidence passage.
- **Precision@k (P@k)**:
$$\text{P@}k = \frac{\text{Relevant Passages in Top-}k}{k}$$

### 3.3 Uncertainty & Calibration Metrics
- **Expected Calibration Error (ECE)**:
Group $N$ predictions into $B$ equal-interval confidence bins (e.g., $B = 10$ bins: $[0, 0.1), [0.1, 0.2), \dots$):
$$\text{ECE} = \sum_{b=1}^B \frac{|B_b|}{N} \Big| \text{acc}(B_b) - \text{conf}(B_b) \Big|$$
where $\text{acc}(B_b)$ is the empirical accuracy of predictions in bin $B_b$ and $\text{conf}(B_b)$ is the average predicted probability.
- **Maximum Calibration Error (MCE)**:
$$\text{MCE} = \max_{b \in \{1, \dots, B\}} \Big| \text{acc}(B_b) - \text{conf}(B_b) \Big|$$

### 3.4 Robustness & Degradation Metrics
- **Relative Performance Drop (RPD)** under noise $\eta$ (compression / paraphrasing):
$$\text{RPD}(\eta) = \frac{\text{Macro-F1}_{\text{clean}} - \text{Macro-F1}_{\text{perturbed}(\eta)}}{\text{Macro-F1}_{\text{clean}}} \times 100\%$$

## 4. Statistical Significance Testing

To prove that improvements of the Multimodal Evidence-Grounded system over the text-only baseline are not due to random chance:

1. **McNemar's Test**: Applied to paired binary classification outcomes on the test set:
$$\chi^2 = \frac{(|b - c| - 1)^2}{b + c}, \quad \text{d.f.} = 1$$
where $b$ is the number of samples correct in Model A but incorrect in Model B, and $c$ is the number correct in Model B but incorrect in Model A.
2. **Wilcoxon Signed-Rank Test**: Applied to fold-wise cross-validation Macro-F1 scores across 5 stratified folds.
3. **Significance Threshold**: The null hypothesis is rejected if $p < 0.05$.
